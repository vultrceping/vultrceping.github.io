Vultr 常见问题解答#

Q1：面向国内用户建站，迈阿密和洛杉矶机房选哪个更好？#

+
如果你的受众 100% 都是国内用户，首选依然是洛杉矶（西海岸），因为物理距离更短，速度更快。但如果你的网站受众是全球或美洲用户，迈阿密反而能提供更稳健的连接。

Q2：Vultr 刚开通的迈阿密 VPS，IP 连不上（被墙）怎么办？#

+

这是国际主流云厂商的通病，因为 IP 经常被上一任用户滥用。

不用担心，Vultr 是按小时计费的。直接在后台将这台机器 Destroy（销毁），然后重新开一台新的，直到随机分配到一个国内能正常 Ping 通的可用 IP 为止。

Q3：共享 CPU (Shared CPU) 会限制我的网站性能吗？#

+

对于日 IP 在几千以内的个人博客、中小型外贸展示站来说，共享 CPU 的算力完全够用。

如果你要跑高并发的大型动态商城，或者需要 24 小时长时间 100% 满载运算的脚本，共享 CPU 稳定性就欠缺很多。这种情况下，建议升级到 Vultr 的独立 CPU (Dedicated CPU) 。

Q4：测评中提到国内晚高峰丢包率偏高，有没有低成本的优化方案？#
